# JOGO DO NUMERO SECRETO:

##  Sobre o projeto

O Jogo do Número Secreto é meu primeiro projeto desenvolvido durante minha transição de carreira para a área de tecnologia.

O projeto foi desenvolvido durante meus estudos na plataforma *Alura*, com o objetivo de colocar em prática os conhecimentos adquiridos em lógica de programação e desenvolvimento web.

O desafio consiste em descobrir um número secreto por meio de tentativas, recebendo dicas para saber se o número informado é maior ou menor que o número correto.


###  Tecnologias utilizadas

> * HTML

> * CSS

> * JavaScript


### Funcionalidades

> * Geração de um número secreto.

> * Validação dos palpites do usuário.

> * Mensagens indicando se o número secreto é maior ou menor.

> * Contagem de tentativas.

> * Opção para reiniciar o jogo.


### Aprendizados

* Durante o desenvolvimento deste projeto, pude praticar conceitos importantes, como:

> * Lógica de programação.

> * Variáveis e operadores.

> * Estruturas condicionais.

> * Funções.

> * Manipulação de elementos HTML com JavaScript.
